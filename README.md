# StockFlow Inventory Management System

A responsive, frontend-only inventory management workspace built with HTML, CSS, and vanilla JavaScript. It uses browser LocalStorage for all persistence—no server, database, framework, or build step is required.

## Run it

Open `index.html` in a modern browser, or serve the project directory with any static-file server.

## Included workflows

- Dashboard, inventory catalog, low-stock monitoring, reports, and settings
- Product, category, supplier, and customer create/read/update/delete flows
- Stock in, stock out, stock adjustment, and an auditable stock-movement log
- Purchase and sale creation with cart totals, tax, stock validation, and automatic inventory updates
- Global search, CSV/data export, JSON import, reset, dark mode, responsive navigation, dialogs, and toasts
